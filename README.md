The course was built in Java with the help of three different labs which built up to a final project of the Game Sokoban

## Sokaban
Sokoban is a japaneaze puzzle game, where the player wins over a level by moving boxes to specific places. 

The games was built with AOOP aspect in mind following a Observer-Subject pattern to handle the events. Which means that different aspects subscribe to different observers which then update based on the subsribtion.
